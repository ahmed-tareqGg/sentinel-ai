# SOCMind - Security Operations Intelligence

Enterprise-grade Security Operations Center (SOC) platform with real-time threat detection, automated incident response, and intelligent security analytics.

## Features

- **Real-time Threat Detection**: Continuous monitoring and analysis of security events
- **Automated Incident Response**: SOAR playbooks for automated containment and remediation
- **Intelligent Analytics**: Advanced analytics and reporting for security operations
- **MITRE ATT&CK Coverage**: Full framework integration for threat classification
- **Compliance Management**: Built-in compliance tracking and audit logging

## Technology Stack

- React 18 with TypeScript
- Vite for fast development builds
- Tailwind CSS for styling
- Supabase for backend services
- Recharts for data visualization

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
